# Карты, соседи и кластеры

## Рабочий сценарий

1. Загрузить папку с Parquet и манифестом.
2. Найти объект по части ID или названия в верхней строке поиска.
   Поиск нечувствителен к регистру.
3. Выбрать оси карты. Нажатие на точку, строку объектов или строку соседей
   переключает карточку и пересчитывает соседей.
4. Выбрать алгоритм и параметры в левой панели и нажать соответствующую кнопку.
   Проекция и кластеризация запускаются независимо.
5. Изучить размеры кластеров, примеры объектов и распределения metadata.

Поиск ограничивает список подсказок, но не вычисления. Таблица объектов имеет
постраничную загрузку. При загрузке другого набора выбор, проекция и кластеры
сбрасываются. При выборе точки или строки сама карта не пересоздаётся: меняются
только подсветка и правая панель. Масштаб и сдвиг сохраняются также при окраске
и фильтрации; новая геометрия или новые оси начинают отдельный вид карты.

Тёмная тема включена по умолчанию; переключатель темы находится сверху.
Размер точек можно увеличить над картой. Тема и размер сохраняются между
открытиями интерфейса и вместе с исследованием. Цвет выделения соответствует
кластеру независимо от выбранной окраски metadata; без кластеризации используется
базовый цвет. Размер и контур выделяют объект, сохраняя его принадлежность к группе.

## Срезы и выделение

Фильтры строятся по полям metadata и объединяются через AND. Для чисел доступны
включительные границы диапазона, для категорий и boolean — выбор значений.
Отсутствующее поле и явный `null` различаются; доступны проверки наличия/отсутствия.
Типы тоже различаются: boolean `true`, число `1` и строка `"1"` — разные значения.
Для вложенных объектов и массивов доступны проверки наличия поля.

Фильтр отображения скрывает точки, сохраняя уже рассчитанные координаты и метки.
Опция вычисления на текущем срезе явно обучает выбранный алгоритм только на нём.
Вне этого среза координаты отсутствуют, а метки кластеров имеют внутренний
маркер `-2` (не вычислено); экспорт представляет их как null/пустые значения.
Шум HDBSCAN остаётся отдельной меткой `-1`.

Область поиска соседей выбирается независимо: весь набор или срез. Если выбранный
объект скрыт фильтром, он остаётся запросом, а кандидаты берутся из выбранной
области. Карта поддерживает одиночный выбор, рамку и лассо; выбранные ID доступны
для экспорта. Окраска поддерживает числовые и категориальные metadata, а также
кластерные метки.

## Геометрия

Исходный Parquet хранит float32; вычисления используют float64. Переключатель
L2-нормализации применяется к каждому вектору перед всеми алгоритмами, включая
карту исходных координат. Нулевые векторы остаются нулевыми. Исходные значения
не изменяются и доступны в карточке вместе со значениями после подготовки.

| Операция | Пространство и смысл |
| --- | --- |
| Исходная карта | Две выбранные координаты подготовленных векторов |
| PCA | Центрированное PCA без whitening; показывается доля объяснённой дисперсии |
| UMAP / t-SNE | Двумерная проекция, метрика euclidean или cosine |
| Точные соседи | Весь набор подготовленных векторов, до PCA/UMAP/t-SNE карты |
| KMeans | Евклидово расстояние; исходное пространство или отдельное PCA |
| HDBSCAN | Euclidean или cosine; исходное пространство или отдельное PCA |
| Spectral | Спектральное разбиение графа ближайших соседей с евклидовой геометрией |
| Agglomerative | Иерархическое объединение; Ward только с euclidean, average/complete/single также с cosine |
| DBSCAN | Плотностные группы по радиусу eps и min_samples; шум имеет метку −1 |
| Gaussian Mixture | Смесь гауссовых распределений с диагональной или сферической ковариацией |

Близость точек на UMAP/t-SNE не равна близости исходных эмбеддингов. Кластеризация
не использует эти двумерные карты: её PCA и число компонент задаются отдельно.
Изменение карты не меняет кластерные метки или соседей. Изменение нормализации
сбрасывает результаты, поскольку меняется геометрия.

KMeans и Gaussian Mixture удобны для компактных групп; у смеси каждая группа
может иметь свою дисперсию. Spectral позволяет искать группы сложной формы через
граф соседства. Agglomerative объединяет ближайшие группы по выбранному правилу.
DBSCAN выделяет плотные области без задания числа кластеров; eps задаётся
в единицах расстояния выбранного пространства и меняет смысл при нормализации.
Все параметры рассчитанного результата доступны в сворачиваемом блоке под формой.

Cosine и dot product возвращают **similarity**: больше — ближе. L2 возвращает
**distance**: меньше — ближе. Выбранный объект исключается, но его дубликат с
другим ID остаётся допустимым соседом. При равенстве значений порядок совпадает
с порядком строк датасета. Для cosine нулевые кандидаты исключаются с сообщением;
нулевой запрос требует другой метрики. Алгоритмы с метрикой cosine отклоняют
наборы с нулевыми векторами, чтобы избежать неопределённой геометрии.

Параметры ограничены размером набора: например, perplexity t-SNE должна быть
меньше числа объектов, а размер PCA — не больше min(N, D). Ошибка вычисления
показывается на странице; предыдущий успешный результат сохраняется. Seed
по умолчанию 42, KMeans использует 10 инициализаций. Повторяемость ожидается
в одном окружении с одинаковыми данными, параметрами и версиями библиотек.

## Сводки кластеров

Шум HDBSCAN и DBSCAN имеет метку `-1` и серый цвет. Для обычных кластеров выбираются до
пяти реальных объектов, ближайших к центроиду в пространстве кластеризации;
для шума — первые пять строк. Для metadata показываются количество пропусков
и null, типы значений, min/max/mean чисел и наиболее частые строки/bool.
Сводки ограничены 12 полями и 8 значениями на поле; усечённые данные обозначены.
Первые 20 кластеров получают контрастные цвета из фиксированной палитры;
для следующих добавляются оттенки. Точный ID и число объектов показаны в легенде,
цветная метка кластера — в карточке объекта.

## Объём данных и время

- Набор и матрицы целиком находятся в памяти. Проекции и кластеры выполняются
  в фоновом потоке по нажатию кнопки; первый UMAP может быть медленным из-за JIT.
  Во время расчёта можно перемещать карту и выбирать объекты. На одну сессию
  выполняется одна исследовательская операция одновременно.
- На карту выводится до 50 000 точек фиксированной случайной выборки плюс
  выбранный объект. Все алгоритмы продолжают использовать **весь набор**.
- Поиск соседей точный: примерно O(N × D) на запрос, без полной матрицы N × N.
  Интерфейс позволяет запросить до 1 000 соседей.
- HDBSCAN с cosine использует полную матрицу расстояний. Если одна такая
  float64-матрица превышает 512 MiB (>8 192 объектов), операция отклоняется.
  Реальная память включает и другие массивы; это ограничение не гарантирует
  максимальный RSS процесса. Можно выбрать euclidean или меньший набор.
- Agglomerative и DBSCAN ограничены 8 192 объектами: для них применяется тот же
  лимит 512 MiB на оценку квадратичных структур. Используйте срез для больших наборов.
- Spectral строит разреженный граф соседства: до 20 000 объектов, до 256 кластеров
  (строго меньше числа объектов), от 2 до min(1 000, N) соседей. Оценка памяти
  графа и лапласиана ограничена 256 MiB. Несвязный граф сопровождается предупреждением;
  попробуйте увеличить число соседей.
- Gaussian Mixture поддерживает до 256 компонент, диагональную или сферическую
  ковариацию. Оценка памяти рабочих матриц EM ограничена 512 MiB. Для эмбеддингов
  большой размерности можно предварительно выбрать отдельное PCA.
- Карта передаёт в браузер до 50 000 точек; исходная матрица остаётся на сервере.
  Отдельные вкладки браузера имеют независимые исследовательские сессии.

## Автоподбор кластеризации

В форме кластеризации есть режимы «Ручной» и «Автоподбор». В автоматическом
режиме задаются алгоритм, **точное число непустых кластеров**, пространство,
seed, критерий и максимальное число вариантов (6/12/24 в интерфейсе,
1–48 в Python/HTTP API). Это ограничение числа запусков, не секунд.
Победитель — лучший из проверенных вариантов, а не гарантированный глобальный
оптимум и не доказательство смыслового качества кластеров.

| Алгоритм | Что перебирается |
| --- | --- |
| KMeans | Воспроизводимые стартовые seed; каждый вариант уже имеет `n_init=10` |
| Spectral | Число соседей в графе, затем дополнительные старты |
| Agglomerative | Ward/average/complete/single и допустимые метрики; всего до 7 вариантов |
| Gaussian Mixture | diag/spherical, регуляризация ковариаций, дополнительные старты |

DBSCAN/HDBSCAN остаются ручными: число кластеров у них является результатом
алгоритма, а шум требует отдельного правила оценки покрытия.

**Внутрикластерный разброс (SSE)** — сумма квадратов евклидовых расстояний
от объектов до среднего своего кластера, вычисленная по всем объектам.
Меньше — лучше; критерий предпочитает компактные группы. **Silhouette**
учитывает внутрикластерные и межкластерные расстояния; больше — лучше.
Он считается с Euclidean на одной фиксированной случайной выборке до 1 000
объектов для всех вариантов. Выборка явно указана в отчёте; она не ограничивает
данные для обучения кластеризации. Для Silhouette требуется от 2 до N−1
непустых кластеров; если на выборке оценка не определена, вариант отклоняется.

Нормализация, состав объектов, размерность и пространство оценки фиксированы
на весь поиск. PCA обучается **один раз**. Проекция карты UMAP/t-SNE в подборе
не участвует. Варианты с ошибкой, шумом или другим числом непустых кластеров
не могут выиграть; причина сохраняется в таблице вариантов. При равных оценках
сохраняется первый вариант. Бюджет может не исчерпаться, если допустимых уникальных
настроек меньше.

Поиск выполняется последовательно в фоне. Карта и прошлые кластеры доступны
до окончания; затем уже рассчитанные метки победителя применяются без повторного
обучения. «В ручной режим» переносит найденные параметры в форму без пересчёта.
Отмена проверяется между запусками и оценками: текущий вызов sklearn должен
завершиться, после чего слот вычислений освобождается. Отмена или ошибка
сохраняет предыдущие кластеры. Во время ожидания отмены нельзя запустить второй fit.

Кеш и файл исследования сохраняют точные метки победителя, критерий, seed,
оценки, параметры и ошибки проверенных вариантов. Ключ поиска отдельно
версионируется и учитывает бюджет и критерий. Веса/метки всех проигравших
вариантов не сохраняются.

```python
from embedding_visualizer.compute.tuning import tune_clustering

search = tune_clustering(matrix, "spectral", n_clusters=12,
    space="pca", pca_components=32, objective="inertia", budget=12,
    random_state=42)
labels = search.result.labels
winning_manual_parameters = search.request
trials = search.report["trials"]
```

HTTP: `POST /api/operation` с `operation="clustering"`, обычными `method`,
`scope`, общими параметрами в `params` и отдельным
`tuning={"objective":"inertia","budget":12}`. Без `tuning` сохраняется ручной
режим. `GET /api/job` возвращает прогресс; `POST /api/job/cancel` запрашивает отмену.

## Кеш, исследования и экспорт

Кеш на диске учитывает содержимое матрицы, порядок и значения ID, названия,
metadata, manifest, параметры алгоритма, seed, нормализацию, состав среза и версии
вычислительных библиотек. Изменение данных под тем же путём не использует старый
результат. Повреждённые файлы кеша игнорируются. Отказ записи кеша не теряет
успешный результат — он остаётся в памяти с предупреждением.

Файл исследования `.npz` содержит JSON-состояние и точные массивы координат/меток
без pickle. Сохраняются выбранные ID, фильтры, источник и fingerprint, параметры,
нормализация, вид карты и сводки кластеров. Открытие файла не запускает алгоритмы
повторно. Если исходный снимок переехал, сначала откройте его по новому пути,
затем исследование: совпадающий fingerprint позволит восстановить состояние.
Если данные изменились, восстановление отклоняется; текущая сессия сохраняется.

Эмбеддинги не копируются в исследование, поэтому исходный Parquet нужно хранить.
CSV/Parquet-экспорт содержит ID, name, metadata в JSON, координаты и кластеры;
область экспорта — выделение, текущий срез или весь набор. Внутренние файлы кеша
и исследования ограничены 512 MiB в сжатом и распакованном виде.

## Независимый Python API

```python
from embedding_visualizer.data import load_dataset
from embedding_visualizer.compute.common import prepare_embeddings
from embedding_visualizer.compute.projections import project
from embedding_visualizer.compute.clustering import cluster
from embedding_visualizer.compute.neighbors import exact_neighbors
from embedding_visualizer.compute.summaries import summarize_clusters

dataset = load_dataset("data/example")
matrix = prepare_embeddings(dataset.embeddings, normalize=True)
projection = project(matrix, "pca", n_components=2)
neighbors = exact_neighbors(matrix, query_index=0, k=5, metric="cosine")
clusters = cluster(matrix, "kmeans", n_clusters=3, space="original")
summaries = summarize_clusters(dataset, clusters.labels, clusters.representation)
```

Результаты содержат фактические параметры, предупреждения и массивы без
изменения входного датасета. Вычислительный пакет не зависит от Streamlit.
